# Python User Registration System

A simple Python project that validates user registration data before creating an account.

## Features

* Name validation
* Email validation
* Password strength validation
* User registration

## Technologies

* Python 3

## Example

```python
result = register_user(
    "Maria",
    "maria@email.com",
    "Senha123"
)

print(result)
```

## Learning Goals

This project was created to practice:

* Functions
* Loops
* Conditional statements
* Exception handling
* Input validation
